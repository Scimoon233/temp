## 课程硬性要求与最终核对

英文PDF含参考文献共3页，所有可提取文字均为12 pt Times New Roman（含粗体及斜体），Word文档为单倍行距。首页的图文摘要为独立生成的本项目结果图，其显示字号同样按12 pt设计。正文双栏。已逐页渲染检查。

期刊正式版的较小字号和15页篇幅由课程明确要求的12 pt、2—3页替代。页面为A4，左右边距1.5 cm，上下1.65 cm；这些是排版选择。课程论文页眉不冒用出版社标志、期刊名称、录用时间或DOI。

中文对应版沿用同样的版式组织，共4页，供阅读核对；英文3页版为课程提交稿。

本次修改不重新运行热模型。原8行结果、参考文献和关键量化结论已对照上一版本核验；CSV及基准参数哈希不变。

## 重新生成

从项目根目录运行（需已安装Times New Roman、中文审阅版另需Noto Serif CJK SC、以及LibreOffice）：

```bash
python -m pip install -r requirements_draft.txt
python model/write_course_essay.py
python model/write_chinese_course_essay.py
soffice --headless --convert-to pdf --outdir course_essay course_essay/Hangzhou_Passive_Cooling_Course_Essay.docx
soffice --headless --convert-to pdf --outdir course_essay_zh course_essay_zh/杭州住宅被动降温_英文短稿对应中文版.docx
```

`model/journal_course_layout.py`集中管理版式和图文摘要。数据从`results/base_metrics.csv`读取，全部项目路径相对脚本所在项目解析。不同编辑器可能改变Word分页，以已核验的PDF为准。
