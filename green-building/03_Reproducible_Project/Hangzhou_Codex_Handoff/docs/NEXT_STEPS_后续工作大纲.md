# Green Building课程论文：后续工作大纲
杭州夏季住宅外遮阳与夜间通风的降温效果及显热制冷需求
版本：v1.0｜日期：2026年11月7日｜性质：模型复核与后续分析任务安排

## 一、当前进度与本轮目标
第一版已完成闭合简化几何、两热区四节点RC模型、两年四情景及自由运行／理想显热制冷两种工况。已有16组基准运行及19组参数变体，共320组季节模拟，并已输出图表、逐时数据和方法说明。
数值检查已通过，但尚未进行实测校准。自由运行基准峰值为2025年50.11°C、2026年47.84°C；组合措施虽改善过热，仍存在大量剩余过热。因此下一步应先解释热量来源和关键假设，再冻结论文主模型，不能仅凭数值守恒或温度“看起来合理”判断模型准确性。
本轮目标：形成来源可追溯、物理路径清楚、结论适用边界明确的模型与分析资料；暂不生成整篇论文定稿。本文件仅列出后续任务，不表示这些复核已完成。

## 三、阶段一：热量收支分解与高温诊断
### 3.1 建立可核对的分区热量账目
分别输出Z1居住区与Z2阳台的直接太阳得热、阳台二次透入分配、内部得热、外墙太阳吸热、围护传热、对外通风、两区交换、空气与蓄热节点储热变化，以及理想制冷移热。
同一热流采用统一正负号。两区间传热在全系统汇总时应相互抵消；阳台透入太阳热在分配至Z1与Z2前后总量必须一致。既报告累计得热／失热，也报告净值，避免正负抵消掩盖机制。
### 3.2 识别高温的主要来源
检查全季、按室外天气选定的代表高温周及峰值日前后过程，区分白天太阳增热、夜间排热不足和蓄热释放。补做零内部得热、零太阳得热等诊断工况，用于辨识机制，不将其混作四个正式研究情景。
### 3.3 交付与完成标准
交付：逐时热流明细、分区季节能量收支表、代表日／周热流图、高温诊断说明。
完成标准：热流可与节点温度变化及移热量闭合；主要热源有量化依据；明确现有高温来自哪些假设及物理路径。不以调低温度为修正目标，也不因没有实测数据而声称已证明其真实准确性。

## 四、阶段二：阳台、遮挡与使用假设复核
### 4.1 阳台太阳得热与二次透入
复核玻璃面积、朝向、关闭隔断及Z1／Z2分配方式。重点检查当前25%有效二次透入份额的含义，是否适合研究目的，以及它与隔断构造是否一致。保留0／25%／50%对照，不将这些数值称为实测透射率。
### 4.2 阳台顶板及既有遮挡
优先评估当前忽略阳台顶板遮挡是否会明显高估太阳得热。如现有资料不足以确定尺寸，可采用有说明的顶板深度或受遮比例对照；新增几何同样登记为假设。
区分住宅本身的既有遮挡与S1／S3新增外遮阳。若修正既有遮挡，四种情景均使用相同修正，避免改变对照基础或重复削减同一束辐射。
### 4.3 隔断、通风与内部得热
复核隔断传导、区间混合和二次透光是否重复计热；区间混合不得当作室外ACH。确认关闭隔断同时允许两区各自对外开窗的假设，并说明现实适用条件。
核对16.7 W/m²的原文含义及当前时序，检验日累计得热量。若采用更低得热基准，应给出资料或研究设计依据，保留原基准对照，不能因高温结果而直接调整。
### 4.4 交付与完成标准
交付：关键假设对照表、修正前后结果、主模型选择说明。
完成标准：说明每项变化影响什么热流、为何采用或保留；若合理建模方式改变方案排序，将结论明确写成有条件结论。

## 五、阶段三：参数来源与输入口径核查
优先获取并核查整窗U值6.7 W/(m²·K)、SHGC 0.70、关闭／开启总ACH 0.44／1.51 h⁻¹对应的原始资料，记录构造类型、适用建筑、样本条件及表号／页码。不能把玻璃中心参数与整窗面积混用；开窗ACH不额外叠加背景ACH。
有效热容量与空气—蓄热耦合继续标为研究假设或探索性参数，不把原材料总热容量直接当作有效容量。对材料表异常值保留原记录，说明是否影响当前计算。
核查天气时区、辐射前一小时均值、温度端点、太阳位置及首尾边界。当前保留2208条数据对应的区间相对严格日历夏季早一小时；需统一选择并记录口径，不编造缺失端点。如改变时间口径，评估这一变化是否影响比较结果。
交付：逐参数证据登记、无法核实项清单、天气与辐射处理说明。
完成标准：每个主参数均能区分原始资料、外部代理、推导与假设；无法取得的来源如实标注，不因此无限延误，也不编造书目或页码。

## 六、阶段四：模型修正、核验与统一重跑
仅实施前述复核支持的必要修正，保留第一版及变更记录。锁定统一几何、围护、热容量、得热、遮阳、通风控制、理想制冷设定和评价时段。
针对实际变更复跑必要检查：能量守恒、无热源等温、太阳得热分配、通风温差与总ACH逻辑、理想制冷约束、步长收敛，以及预热和初始状态影响。现有检查可以复用；不得把程序核验称为实测校准。
主模型或控制有变化时，重新运行两年×四情景×两工况的16组基准，并重跑受影响的敏感性组。若没有实质变化，不为增加次数重复全部模拟。
交付：版本化配置、源码、核验记录、逐时数据、统一结果表及相对路径运行命令。
完成标准：任一正式结果都能追溯到配置、源码和输入文件；方案之间只存在已定义的措施差异，比较使用相同评价口径。

## 七、阶段五：敏感性、夜间条件及组合交互
### 7.1 敏感性与排序
在确定的主模型下复核ACH、有效热容量、窗面积和遮阳强度；保留与阶段二有关的关键假设对照。各变体都与其自身S0比较，报告绝对变化、相对变化和四方案排序。
已有OAT分析可以继续使用，不必无依据增加参数网格。只有发现明显交互或排序不稳定时，再选少量有物理依据的多参数组合；有限情景范围不解释为置信区间。
### 7.2 夜间通风机会
分别统计夜间窗口、满足温差条件及实际开启的时数，联系室外夜间温度、室内状态和排热量解释收益。自由运行与26°C理想制冷工况应分开分析；固定ACH模型不能据此推断真实风速或风压效果。
### 7.3 交互与剩余过热
使用Bi=D0−Di、I=B3−B1−B2判断超相加、近似相加或收益递减；组合最好不自动等于协同。保留不利结果，同时报告S3剩余过热与显热需求，不只报告改善百分比。
交付与完成标准：形成敏感性汇总、排序表、夜间机会及交互表；能够回答“何种条件下有效、效果多大、哪些结论随假设改变”。
