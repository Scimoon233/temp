## MATLAB 运行

将 MATLAB 当前目录切换到 `code`，执行：

```matlab
results = fem3d_p2;
```

程序依次执行 n=2 的非齐次边界多项式测试，n=4,8,16 的正弦解实验，以及 n=4 的积分精度对照。结果输出到 `matlab_results`，包括 CSV、MAT 文件和截面节点散点图。函数也允许指定输出目录：

```matlab
results = fem3d_p2('my_results');
```

三级正弦实验应得到约为以下数量级的误差：

| n | NV | NE | 内部未知量 | E0 | E1 |
|---|---|---|---|---|---|
| 4 | 125 | 604 | 343 | 5.665e-3 | 1.690e-1 |
| 8 | 729 | 4184 | 3375 | 7.041e-4 | 4.498e-2 |
| 16 | 4913 | 31024 | 29791 | 8.777e-5 | 1.147e-2 |

浮点误差和残差会随求解器、编号与运行环境略有变化。若规模或误差量级明显不符，应先检查程序输出，不要直接修改展示中的表格。

## Python 运行

需要 Python 3、NumPy、SciPy；核心求解程序不依赖 Matplotlib。安装依赖后，在 `code` 目录运行：

```text
python -m pip install numpy scipy
python fem3d_p2.py
```

输出写入相邻的 `data` 目录。程序包含必要的断言检查：节点对偶关系、正确/单点局部刚度秩、二次多项式再现、网格加密后误差下降，以及积分精度敏感性。

## 算法约定

1. 单位立方体每个方向分 n 段，各小立方体按全局一致的 Kuhn 剖分分为六个四面体。NT=6n³，最大直径 h=√3/n。
2. 固定局部边为 (12),(13),(14),(23),(24),(34)。总自由度 N=NV+NE；内部未知量需扣除边界顶点和边界边中点。
3. 由排序后三顶点的出现次数确定边界面；由边界面得到边界边。
4. 刚度用四点二次精确求积。重心坐标点为 a=(5+3√5)/20、b=(5−√5)/20 的四种排列，每点权重 1/4。
5. 载荷与误差使用每个方向五点的 Duffy-Gauss 规则，共 125 点。Duffy 映射为 ξ=r、η=(1−r)s、ζ=(1−r)(1−s)t，Jacobian 为 (1−r)²(1−s)。权重乘六后和为一，物理积分乘 |T|。
6. f 在每个求积点计算，没有采用单元重心值 fmid 替代。
7. 多项式测试精确解为 x²+y²+z²+xy+xz+yz，右端 −6，边界取精确数据。正弦测试为三个 sin(π·) 的乘积，右端 3π²u。
8. 残差只检查内部方程，相对归一化分母采用提升后内部右端的范数。
9. 最细网格截面图显示 z=0.5 平面上的 P2 节点采样；误差图也是这些节点上的绝对误差，不能替代三维积分误差。
