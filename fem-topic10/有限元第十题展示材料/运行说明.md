## Python运行

在code目录执行：

```text
python -m pip install numpy scipy
python fem3d_p2.py
```

程序运行单元核验、n=2非齐次多项式测试、n=4,8,16正弦解实验，以及粗网格求积精度对照。输出写入相邻data目录。核心求解无需Matplotlib。

可选的稀疏存储检查：

```text
python -m pip install matplotlib
python inspect_sparsity.py
```

该脚本只组装n=16矩阵，不重新求解。11.3 MiB只指最终CSR三个数组，不包括组装临时数组、分解填充和进程其他开销。图中977,793个存储条目包含184,832个显式零。

## MATLAB运行

MATLAB R2016b或更新版本，无需额外工具箱。在code目录执行：

```matlab
results = fem3d_p2;
```

输出写入matlab_results，包括CSV、MAT文件和截面节点散点图。也可指定输出目录：

```matlab
results = fem3d_p2('my_results');
```

## 算法约定与来源

每个小立方体采用全局一致的Kuhn六四面体剖分，NT=6n³，h=√3/n。局部边顺序固定为(12),(13),(14),(23),(24),(34)。边界由只出现一次的排序面三元组确定，再提取边界边及完整自由度。

刚度用二次精确四点规则；载荷与误差用每方向五点的Duffy–Gauss规则，共125点。全部四面体权重归一化到和为1，物理积分乘单元体积。f在每个求积点计算。

Note0第9页起提供二次元与参考映射思路；Note1第8–10页提供组装与非齐次边界提升；Note2第8–12页提供二次节点形函数、连续性、边编号与高阶元组装。三维网格、面拓扑和四面体积分为本次推广实现。未获取补充讲义和HW2，不声称已核对其全部内容。
