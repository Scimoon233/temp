# 展示准备清单：必须搞明白的概念与问题

目标：不依靠背稿，也能解释“这个程序为什么这样写，结果为什么可信”。下列每题都附有回答要点；能用自己的话讲清楚并指出对应代码，才算掌握。

## A. 必须理解的 12 个概念

- [ ] 1. 强形式与弱形式。
  能从 −Δu=f 出发，乘测试函数、积分并分部积分，得到 ∫∇u·∇v=∫fv。Dirichlet 问题中测试函数在边界为零，因此边界积分消失。
- [ ] 2. 试探函数空间与测试函数空间。
  齐次边界时两者都采用 Vh,0；非齐次边界时 uh 属于带给定边界数据的仿射集合，测试函数仍属于 Vh,0。不能直接把带非零边界值的 uh 写成 Vh,0 的元素。
- [ ] 3. P2 到底表示什么。
  三维 P2 是总次数不超过二的多项式，基可取 1,x,y,z,x²,y²,z²,xy,xz,yz，共十个。它不同于三个方向分别二次的 Q2，后者维数为 27。
- [ ] 4. 自由度与解系数。
  这里采用节点型 Lagrange 基，自由度是四个顶点值、六个边中点值；由于节点对偶关系，展开系数就是这些节点处的函数值。边中点坐标由端点平均得到，但解值通常不等于端点解值的平均。
- [ ] 5. 重心坐标。
  x=Σλᵢaᵢ，Σλᵢ=1；每个 λᵢ 是仿射函数，在第 i 个顶点为一、其他顶点为零。它的梯度在单元内为常向量。
- [ ] 6. 形函数与多项式再现。
  顶点形函数为 λᵢ(2λᵢ−1)，边形函数为 4λᵢλⱼ。能够验证十节点取值矩阵为单位阵，因而这十个函数是 P2 的一组基。形函数之和为一。
- [ ] 7. 局部自由度与全局自由度。
  每个四面体有十列局部编号，但不同单元共享的顶点与边中点只对应一个全局未知量。施加边界条件前 N=NV+NE；内部未知量数还需扣除边界自由度。
- [ ] 8. 连续性与协调性。
  公共三角形面上的三个顶点和三个边中点确定整个二次面迹，六个值匹配即保证面迹相同。全局函数连续且分片光滑，因此属于 H1；一般梯度跨面不连续，不能说它是 C1。
- [ ] 9. 仿射变换与积分缩放。
  B 的三列为 a₂−a₁、a₃−a₁、a₄−a₁；∇xφ=B⁻ᵀ∇ξφ̂，dx=|det B|dξ，体积 |T|=|det B|/6。梯度要保留实际 B 的方向信息；测度使用行列式绝对值。
- [ ] 10. 求积精度与权重约定。
  梯度一次，梯度点积二次，故常系数刚度需要二次精确规则。本程序四面体权重和为一，积分乘物理体积。如果权重和为 1/6，则应乘 |det B|。两种约定不能混用。
- [ ] 11. 边界提升与消元。
  先把边界值填入 Ub，再解 AII UI=bI−AIB gB。程序中 b−AUb 正是右端修正。边界处原方程不再作为待求方程；残差应检查内部自由度。
- [ ] 12. 三类误差不能混淆。
  E0 是整个区域的函数值 L2 误差；E1 是梯度的 L2 误差，即 H1 半范数误差；残差检查离散代数方程。另有数值积分误差与浮点误差。残差小不保证离散空间能很好逼近精确解。

## B. 必须能解释的 8 段程序

- [ ] 1. `cube_mesh` / `mesh`：为什么相邻小立方体的三角形公共面能够匹配？
  使用全局一致坐标方向的 Kuhn 剖分，每个立方体由六条单调坐标路径形成六个四面体；共享面上的剖分相同。任意逐块随意选体对角线可能造成不协调网格。
- [ ] 2. `sort + unique + reshape`：怎样得到 `elem2edge`？
  排序统一无向边的端点表示，去重得到全局边表，逆映射恢复每条局部边对应的全局编号。注意本程序 MATLAB 按六个边块拼接，Python 按单元拼接，reshape 的规则随各自存储顺序一致安排，不能混搭。
- [ ] 3. `elem2dof=[elem,NV+elem2edge]`：每一列对应哪一个形函数？
  前四列是顶点；后六列按 (12),(13),(14),(23),(24),(34) 排列。修改局部顺序必须同时修改形函数、矩阵和映射。
- [ ] 4. 物理梯度 `G`：为什么不能把参考梯度直接用在所有单元？
  单元的尺寸、剪切与方向不同，必须经过 B⁻ᵀ。MATLAB 源码用叉积除以带符号行列式计算相同的物理重心坐标梯度；体积另取绝对值。
- [ ] 5. `COO→CSR` 和 `bincount` 为什么能组装？
  转换 CSR 时，同一全局行列位置的多个局部贡献被相加；载荷用 bincount 按编号累加。这对应 Note2 的 sparse 与 accumarray。矩阵条目代表基函数支撑交叠的积分。稀疏性来自局部支撑，不能说每个单元都创建了一个互不相关的全局未知量集合。
- [ ] 6. 边界面计数与边界边提取。
  面的三顶点排序、计数；只出现一次的是边界面。从这些面提取边界边，不能用“两个端点都是边界点”替代。角点和多面共享边要去重。
- [ ] 7. `b=rhs-A*U` 以及 `U(free)=A(free,free)\b(free)`。
  前者扣掉已知边界对内部方程的贡献，后者只解内部自由度。非齐次边界测试最容易暴露漏修正错误。
- [ ] 8. 误差积分。
  uh(xq)=ΣUiφi(xq)，∇uh(xq)=ΣUi∇φi(xq)，分别计算差值平方和梯度差模平方，乘权重与体积，全局累加后开平方。不能仅对节点误差求平均来代替 E0 或 E1。

## C. 最可能被问到的 12 个问题

### 1. 为什么三维 P2 只有十个自由度？
三维二次多项式有十个单项式；四顶点加六边中点正好十个。更关键的是这十个点值唯一确定多项式，可由十个对偶形函数验证，而不能只凭“数量相同”就断言唯一可解。

### 2. 为什么只给边界顶点赋值不够？
边界面迹是一个六自由度的二次三角形多项式。只令三个顶点为零，仍可有非零的边中点值，例如面上的 4λ₁λ₂，因此整个面迹不一定为零。

### 3. 为什么两个边界端点不能决定一条边是边界边？
单位立方体的体对角线就是反例：两个端点在边界，但中点 (1/2,1/2,1/2) 在内部。在本次 Kuhn 网格中，它确实是网格边。必须由边界面识别边界边。

### 4. 为什么共享面六个节点匹配就足够？
把两个相邻单元的函数差限制到公共面上，得到三角形上的 P2 多项式。它在三个顶点、三个边中点为零，由二维 P2 的唯一可解性可知整个面上为零。该论证正好连接 Note2 的二维元与三维拼接。

### 5. 为什么重心单点求积不够？
刚度被积函数一般是二次，单点规则仅具有一次精确性。在重心，四个顶点形函数的梯度甚至全部为零，因为 4λᵢ−1=0。单点近似矩阵可写成 |T|DDᵀ，其中 D 为 10×3，所以秩至多三；正常四面体 Poisson 局部刚度秩为九，唯一零模是常数。单点规则引入额外零能量模式。本次单元检查的两种秩分别为 3 和 9。

### 6. 四点规则用于刚度已经足够，为什么载荷还用更多点？
载荷被积函数是 fφi。如果 f 是正弦函数，它不是二次多项式；误差积分同样包含非多项式项。刚度积分精确不意味着载荷和误差积分也精确。

### 7. 为什么 Note2 的 `fmid` 没有直接照抄？
保留的是讲义的边自由度、局部形函数与组装方法。为了满足本题的精度检查，在每个求积点计算 f(xq)。把 f 固定为单元重心值会额外近似载荷，不宜不经核验就用于本题。

### 8. 为什么多项式测试要用非齐次边界？
所选二次多项式在边界上一般不为零。它既能测试 P2 再现性，也能测试完整边界自由度及 b−AUb 的右端修正。若只做齐次问题，漏掉非齐次修正的错误可能被隐藏。

### 9. 再现测试为什么仍有 10⁻¹⁵ 量级误差？
精确算术中满足相应精确积分和精确边界表示时可以恢复该多项式；实际存在浮点运算、求解误差和求积点表示误差。不能承诺任意网格与规模下误差都固定在 10⁻¹⁵。

### 10. 残差已经 10⁻¹³，为什么 E0 仍约为 10⁻⁴？
它们衡量不同对象：前者检查线性系统，后者检查有限元解与连续精确解。正弦函数不属于有限维 P2 空间，精确求解离散系统后仍然存在逼近误差。

### 11. 能不能说程序证明了三阶 L2、二阶 H1 收敛？
可以说三组结果与光滑解下典型的 O(h³)、O(h²) 行为一致；三级实验不是理论证明。标准估计需要解足够光滑、网格形状正则，以及 L2 提升所需的对偶正则性等条件。本题重点是实现核验，不要求完整证明。

### 12. 实验到底在哪里运行？哪些部分参考讲义？
如实回答：交付数据来自 Python / NumPy / SciPy 的配套实现，MATLAB 源码按同一算法编写，交付环境未运行 MATLAB。编号和向量化组装参考 Note2 第 11—12 页，非齐次边界提升参考 Note1 第 10 页；本次实现补充三维网格、六边编号、边界面识别、四面体积分与实验核验。若你已在自己的 MATLAB 复现，才补充相应运行环境与结果。
